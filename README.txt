RANI BIRTHDAY WEBSITE — ONE-FILE GITHUB PAGES PACKAGE

This package contains ONE file: index.html. All 9 photos, CSS and JavaScript are embedded inside it. No images folder or separate CSS/JS upload is needed.

UPLOAD STEPS
1. Extract this ZIP on your computer.
2. Open your GitHub repository.
3. At the repository ROOT (not inside a subfolder), choose Add file -> Upload files.
4. Upload index.html from this extracted folder. If an index.html already exists, replace/overwrite it.
5. Click Commit changes.
6. Open Settings -> Pages. Set Source = Deploy from a branch, Branch = main, Folder = /(root), then Save.
7. Wait for deployment. Open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/

IMPORTANT
- Do NOT upload the ZIP itself.
- Do NOT put index.html inside a nested folder. It must be at the repository root.
- If your site already opens but images were missing, this one-file version avoids missing image paths because all 9 photos are embedded in index.html.
- If the site still gives 404, the problem is the repository name or GitHub Pages settings, not the images.
